Most productivity tools measure total screen time. ProcrastiSense AI studies how you procrastinate — the sequence, timing and triggers behind every switch away from focused work — and builds a personal Digital Procrastination Fingerprint.

⬤ Real-Time Mode — collection starts only when you start a focus session

THE PROBLEM

Screen-time totals hide the pattern that actually matters.

Knowing you spent "3 hours on your phone" doesn't explain when you lose focus, why, or what happens right before it. Generic blockers apply the same rule to everyone, at every hour, regardless of task difficulty.

01

Aggregate, not behavioral

Total usage numbers say nothing about the sequence of app switches that led there.

02

Reactive, not predictive

Most tools intervene only after a distraction has already started.

03

Generic, not personal

A 25-minute Pomodoro doesn't fit everyone — your own distraction window is unique to you.

PRIVACY-FIRST BY DESIGN

We track categories, not content.

The desktop collector — and this prototype's data model — are built to record behavioral signal only.

  • Application name & category, timestamp, duration, focus label
  • No passwords, ever
  • No keystroke logging
  • No message or document content
  • No screenshots by default
  • Data export and deletion: not available in this prototype

    Privacy & Ethics

    What this system collects — and what it does not collect

    What the Collector Records

    The desktop collector records only the signals listed below. Nothing here is a setting you can switch on or off.

    Collected

    • Application or website name and category
    • Timestamp
    • Duration of each activity block
    • Focus label (Focused / Distracted)
    • Task type and difficulty you selected
    • App switches (derived from consecutive records)

    Never collected

    • Passwords
    • Keystrokes
    • Message contents
    • Screenshots
    • Page or document contents
    • Web addresses (URLs)
    Consent & Control
    • Collection starts only after you press Start Focus Session while the desktop collector is running, and stops when you end the session
    • Only application or website name and category are recorded — never raw content
    • Window titles are read on your computer to recognise websites such as YouTube; the title text is not saved to the database or sent to the server
    • Records are stored in a local SQLite database linked to your account; records you add on the Data Collection page are stored the same way and marked as manual
    • Not implemented in this prototype: a consent dialog, data export, data deletion and idle-time tracking

    Problem & Solution

    Traditional productivity tools mostly measure screen time. They do not understand an individual's personal procrastination pattern. ProcrastiSense AI learns behavioral patterns, identifies a personal digital procrastination fingerprint, predicts upcoming distraction, explains why the risk is increasing, and provides a personalized intervention.
